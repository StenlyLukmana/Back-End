# Back-End Development (Laravel)
## 🧠 Overview
A Laravel-based back-end project in the form of an e-commerce web application.

## 🚀 Features
- API implementation
- CRUD operations with MySQL
- Authentication and authorization
- MVC structure
- Blade templating
- Bootstrap implementation

## 🧰 Technologies Used
- Laravel
- PHP
- MySQL
- Postman
- Bootstrap
